#  TP 



## comandos


- Levanta la VM en el puerto que le definimos (Valgranfile). Una vez finalice ir a http://localhost:8085/

```bash 
vagrant up
```

- Conectarnos a la VM por ssh

```bash 
vagrant ssh  
```

- Ver dentro de la VM lo que existe en la carpeta /vagrant
```bash 
sudo ls -l /vagrant
```
